# LEVEL0

**主代码：** `LEVEL0.py`

本代码主要分两部分：

- 测试环境是否成功，包含torch以及cuda环境
- 设置了一个矩阵乘法，使其在cpu和gpu上运行，对比其效果差异

## 得到的结果：

| 项目 | 值                                  |
| :--- |:-----------------------------------|
| torch 版本 | 2.11.0+cu128                       |
| torch 编译时带的 cuda 版本 | 12.8                               |
| cuda 是否可用 | True                               |
| 显卡名称 | NVIDIA GeForce RTX 5060 Laptop GPU |
| 本次使用的设备 | cuda                               |
| cpu平均耗时 | 145.4 ms                           |
| gpu平均耗时 | 14.4 ms                            |

结果显示环境配置成功，且在运算上

CPU耗时约为GPU的10倍，体现了GPU的优越性，所以后续的程序一般以在GPU上跑为佳
