# LEVEL1

用 MLP完成 MNIST 手写数字识别。

**主要代码：** `LV1_MLP.py`与`LV1_MLP_2.PY`

| 项目 | 内容 |
| :--- | :--- |
| 模型结构 | 784 -> 256 -> 128 -> 10 (全连接层 + ReLU 激活，最后一层用softmax，但是有crossentropy，所以不用写) |
| 损失函数 | CrossEntropyLoss |
| 优化器 | Adam |

- 训练结束后保存 loss 曲线到 DRAW/MLP_DRAW。
- 得到的模型权重保存到./model/level1_model.pth中
- 因为已经进行了训练，所以在最后的执行函数中，对train函数进行了注释，运行程序仅得到测试结果准确率
- 如果需要重新训练，要将注释取消，训练流程大概耗时1分钟

## 网络结构

- 将图片得到的tensor类型展开
- 全连接层1，输入 `28*28` 的图片，输出256个神经元  +  RELU激活函数
- 全连接层2，输入上一层的256个神经元，输出128个神经元  +  RELU激活函数
- 全连接层3（output），输入上一层的128个神经元，输出10个神经元，即最后分类的类别

## 超参数：

```python
BATCH_SIZE = 64                # 每次从数据加载器输入的样本数
EPOCHS = 10                    # 训练的轮数
LR = 0.001                     # 学习率
HIDDEN1 = 256                  # 第一个隐藏层神经元个数
HIDDEN2 = 128                  # 第二个隐藏层神经元个数
torch.manual_seed(0)           # 设置随机种子，这样结果可以复现
```
